## What RAM Structural System Is

RAM Structural System is a building-structure workspace where gravity framing and lateral analysis share one project. RAM Structural System gravity framing tracks beams, columns, and joists by story so each floor stays stacked on the levels below it. RAM Structural System story data carries that layout into RAM Structural System lateral analysis, where frames are read before member sizing. Gravity members and lateral members remain in the project instead of being split into unrelated models.

Building engineers open RAM Structural System when floors repeat and wind or seismic frames must be checked against the gravity system. Story names, beam lines, and column stacks stay visible while member sizing follows the analysis. RAM Structural System keeps gravity framing, lateral analysis, and member sizing on the building you will review.
